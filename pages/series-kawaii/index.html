1

Le pitch : une suite, une fonction

Une série génératrice transforme une suite \((a_n)\) en une seule fonction \(f\), dont les coefficients de Taylor sont exactement les \(a_n\).

\[ (a_n)_{n\ge 0} \;\longmapsto\; f(x)=\sum_{n=0}^{+\infty} a_n x^n \]

\(x^n\) sert d'étiquette pour la case n, et \(a_n\) est ce qu'on range dedans. Les opérations sur les fonctions (multiplier, dériver) deviennent des opérations sur les suites (convoler, multiplier par n).

1. Encodersuite → \(f(x)\), en vérifiant \(R>0\)
2. Calculerdériver, multiplier, décomposer
3. Identifierlire \(a_n\) grâce à l'unicité

Quand le chemin direct sur la suite bloque, on fait un petit détour par les fonctions !

2

Le terrain de jeu : séries entières et rayon

LEMME D'ABEL

Si \((a_n z_0^n)\) est bornée, alors \(\sum a_n z^n\) converge absolument pour tout \(|z|<|z_0|\). Preuve : \(|a_n z^n|\le M\,|z/z_0|^n\), terme d'une série géométrique convergente.

Rayon de convergence.

\[ R=\sup\{\,r\ge 0 \;:\; (a_n r^n)_n \text{ bornée}\,\}\in[0,+\infty] \]

Convergence absolue pour \(|z|<R\), divergence grossière pour \(|z|>R\). Sur le cercle \(|z|=R\), tout peut arriver.

  • d'Alembert : si \(|a_{n+1}/a_n|\to\ell\), alors \(R=1/\ell\).
  • Comparaison : si \(|a_n|\le|b_n|\), alors \(R_a\ge R_b\) ; si \(a_n\sim b_n\), alors \(R_a=R_b\).
  • Hadamard (hors programme mais pratique) : \(1/R=\limsup |a_n|^{1/n}\).

Sur \(]-R,R[\), la somme est \(C^\infty\), et on dérive ou intègre terme à terme sans changer le rayon :

\[ f'(x)=\sum_{n\ge1} n\,a_n x^{n-1}, \qquad \int_0^x f=\sum_{n\ge0}\frac{a_n}{n+1}x^{n+1} \]

5

Le théorème qui fait tout marcher : l'unicité

FORMULE DE TAYLOR

Si \(f(x)=\sum a_n x^n\) sur \(]-R,R[\) avec \(R>0\) :

\[ a_n=\frac{f^{(n)}(0)}{n!} \]

On dérive n fois terme à terme puis on évalue en 0 : seul le terme de degré n survit.

Unicité. Si \(\sum a_n x^n=\sum b_n x^n\) sur un voisinage de 0, alors \(a_n=b_n\) pour tout n. Il suffit même qu'elles coïncident sur une suite de réels non nuls tendant vers 0.

  • f paire ⟹ coefficients impairs nuls ; f impaire ⟹ coefficients pairs nuls.
  • Deux calculs d'une même fonction donnent une identité. Avec \((1+x)^m(1+x)^p=(1+x)^{m+p}\) :
\[ \sum_{k=0}^n\binom{m}{k}\binom{p}{n-k}=\binom{m+p}{n} \quad\text{(Vandermonde)} \]
PIÈGE

\(C^\infty\) ne suffit pas : \(x\mapsto e^{-1/x^2}\) (avec 0 en 0) a toutes ses dérivées nulles en 0 mais n'est pas nulle.

♡ Méthode 1 : récurrence → fraction rationnelle (Fibonacci)

\(F_0=0\), \(F_1=1\), \(F_{n+2}=F_{n+1}+F_n\), et \(f(x)=\sum F_n x^n\).

  1. R > 0 d'abord ! Par récurrence \(0\le F_n\le 2^n\), donc \(R\ge 1/2\).
  2. Traduire la récurrence avec le dico :
    \[ f(x)-x=x f(x)+x^2 f(x)\;\Longrightarrow\; f(x)=\frac{x}{1-x-x^2} \]
  3. Décomposer avec \(\varphi=\frac{1+\sqrt5}{2}\), \(\psi=\frac{1-\sqrt5}{2}\) :
    \[ f(x)=\frac{1}{\sqrt5}\left(\frac{1}{1-\varphi x}-\frac{1}{1-\psi x}\right) \]
  4. Identifier :
    \[ F_n=\frac{\varphi^n-\psi^n}{\sqrt5} \]

Réflexe mignon : le rayon d'une fraction rationnelle, c'est la distance de 0 au pôle le plus proche. Ici \(1/\varphi\approx 0{,}618\) !

♡ Méthode 2 : équation différentielle (\((1+x)^\alpha\))

\(g(x)=(1+x)^\alpha\) est l'unique solution sur \(]-1,1[\) de \((1+x)g'=\alpha g\), \(g(0)=1\).

  1. Analyse : en injectant \(\sum a_n x^n\), on trouve \(a_{n+1}=\frac{\alpha-n}{n+1}a_n\), \(a_0=1\).
  2. Rayon : \(\alpha\notin\mathbb N\) donc \(a_n\ne0\) et \(|a_{n+1}/a_n|\to1\) : \(R=1\).
  3. Synthèse : la série résout le même problème de Cauchy linéaire, donc elle vaut g par unicité.

ABEL RADIAL (EXERCICE CLASSIQUE)

Si \(\sum a_n\) converge, alors \(f(x)\to\sum a_n\) quand \(x\to1^-\). D'où \(\ln 2=1-\frac12+\frac13-\cdots\). La réciproque est fausse : \(\frac{1}{1+x}\to\frac12\) mais \(\sum(-1)^n\) diverge.

PIÈGES FRÉQUENTS
  • Calculer avant d'avoir prouvé \(R>0\).
  • Croire que le rayon d'un produit vaut exactement le minimum.
  • Oublier les premiers termes dans un décalage d'indice.
  • Conclure sur le bord avec le rayon seul.
