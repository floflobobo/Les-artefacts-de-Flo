# Les artéfacts de Flo

Mes fiches, cartes et jeux de révision (DFGSP2, pharmacie Toulouse), rangés par matière.

Site : https://floflobobo.github.io/Les-artefacts-de-Flo/

- `index.html` — la page d'accueil (liste des artéfacts, recherche, filtres par matière).
- `pages/<nom>/index.html` — une copie de chaque artéfact.

Les documents et designs Claude (fiches Starling, chimie générale, champignons, cartes du glucose et des lipides…) ne fonctionnent que sur claude.ai : l'accueil renvoie vers eux.

Pour ajouter un artéfact : déposer son HTML dans `pages/<nom>/index.html`, puis ajouter une ligne dans le tableau `ITEMS` de `index.html`.
